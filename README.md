# CIFAR-10 Image Classification with Transfer Learning

## Project Overview
This project focuses on image classification using Deep Learning and Transfer Learning with the CIFAR-10 dataset.

## Objectives
- Explore and preprocess the CIFAR-10 dataset.
- Apply Transfer Learning using the pre-trained VGG16 model.
- Train a deep learning model to classify images into 10 categories.
- Evaluate model performance using classification metrics.

## Technologies
- Python
- TensorFlow and Keras
- VGG16
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
CIFAR-10 contains 60,000 color images of size 32x32 pixels, divided into 10 classes:
50,000 training images and 10,000 test images.
